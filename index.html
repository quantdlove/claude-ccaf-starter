🎯 What is CCAF?

Claude Certified Architect Foundations is Anthropic's certification for building production AI agent systems. It tests whether you can design, configure, and maintain Claude-powered pipelines that are reliable, secure, and well-architected.

The exam covers five domains, each weighted by importance. A passing score is 720 out of 1000. This starter kit gives you the building blocks: a CLAUDE.md template, architecture patterns, an audit checklist, and a full worked example you can study.

💡 New to Claude agents? Start with the Five Domains below to understand the framework, then browse the Pattern Catalog to see how production systems are actually built.

📊 The Five CCAF Domains

27% of exam
D1: Agentic Architecture
Pipeline design, tiered autonomy, state management. Can you draw the system?
20% of exam
D3: Claude Code Config
CLAUDE.md as spec. Skills, commands, rules. Security model and hooks.
20% of exam
D4: Prompt and Output
Structured prompts, output schemas, delivery format, quantitative rigor.
18% of exam
D2: Tool Design and MCP
Right tool for the job. Transport architecture. Search vs. query. Error handling.
15% of exam
D5: Context and Reliability
One source of truth. Circuit breakers. Silent failure prevention. Data freshness disclosure.

⚡ Quick Start

1
Copy CLAUDE.md to your project root. Replace "Acme Analytics" with your company. Fill in your team, rules, agents, and folder structure.
2
Create .claude/skills/, .claude/commands/, and .claude/rules/ directories. Use the examples as templates.
3
Run the audit checklist against your system. Fix any red-line failures first.
4
Read the pattern catalog when you hit a design decision. Each pattern links to the CCAF domain it addresses.
